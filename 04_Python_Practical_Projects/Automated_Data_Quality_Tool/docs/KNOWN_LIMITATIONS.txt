KNOWN LIMITATIONS - CURRENT RELEASE
===================================

- Input formats: CSV and XLSX only; legacy XLS is not supported.
- Headerless input requires manual, explicit column_order configuration.
- Fuzzy/potential duplicate scoring is not implemented.
- No automatic email sending.
- No database, CRM, cloud-drive or API integration.
- No comprehensive country-specific phone validation.
- No universal date-format inference.
- Client-specific mandatory fields and cleaning rules must be agreed and
  configured; the tool must not silently guess them.
- For Excel files, confirm the correct worksheet before processing.
- Review output reports before sending cleaned data to a client.
